# Data

- `demo_products.json`: 120 synthetic products generated by `main.py`, with fictional GBP per-item prices.
- `agent_train.jsonl`: 12 synthetic question/tool-decision pairs.
- `agent_eval.jsonl`: 6 separate examples for routing evaluation. Product IDs in these examples are placeholders, not catalogue lookup targets.

`download_catalog.py` optionally creates `public_products_raw.jsonl` from the Home and Kitchen metadata in [Amazon Reviews 2023](https://amazon-reviews-2023.github.io/), collected by McAuley Lab. This downloaded file is excluded from version control. Follow the source dataset's terms and citation guidance when using it.

Source reference: Hou et al. (2024), *Bridging Language and Items for Retrieval and Recommendation*, [arXiv:2403.03952](https://arxiv.org/abs/2403.03952).
